
# Assignment 4 – Project: Laundry Services Web App

## Project Overview

A simple, Web application for Laundry Services built using HTML5, CSS3 and JavaScript.

## Features

- Orders placing system
- Email Confirmation
- Newsletter Subscription Section for future updates

## Technologies Used

- HTML5
- JavaScript
- CSS3
  - Flexbox

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Login to the emailjs website. create account and setup the .env file keys as mentioned in the .env.example. If required use the template.html content to create the email template in the emailjs platform. ["emailjs platform link"](https://www.emailjs.com/)
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.
