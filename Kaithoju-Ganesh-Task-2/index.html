Laundry Mart

Laundry Mart is a web application that allows users to book laundry services online. The application provides a user-friendly interface for users to select the type of laundry service they need, the number of clothes, and the preferred pickup and delivery times. The application also provides a detailed pricing table that displays the cost of each service. Users can also contact the laundry service provider for more information regarding pricing and make a deal with them. The application is built using HTML, CSS, and JavaScript.
