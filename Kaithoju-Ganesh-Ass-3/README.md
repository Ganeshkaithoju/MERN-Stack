# Assignment 3 – DOM Implementation

## Project Overview

A simple, DOM Implementation built using HTML5, CSS3 and JavaScript.

## Features

- An input field to get the user's name, which is useful in greeting the user.
- Change the backgroundColor of the respective color mentioned in the box when clicked.

## Technologies Used

- HTML5
- JavaScript
- CSS3
  - Flexbox

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## Assignment Requirements

- Create an HTML file that includes the following elements: Header with the text "Hello" initially.
- Four boxes with text as red, blue, green, and yellow respectively.
- An input field to get the user's name.
- A button to greet the user.
- Style the elements using CSS to make the layout visually appealing.
- Implement JavaScript functionality to: Change the greeting message in the header to "Hello, [name]" when the button is clicked.
- Change the background colour of the boxes to the respective colour mentioned in the box when clicked.
