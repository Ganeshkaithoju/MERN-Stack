# Assignment 2 – Laundry Services Hero Section

## Project Overview

A simple, responsive laundry service website hero section built using HTML5 and CSS3.

The project focuses on creating a navigation bar and an attractive hero section to introduce laundry services.

## Features

- Navigation bar with Home, Services, About Us, and Contact Us links.
- Laundry service logo on the left and username on the right.
- Responsive hamburger navigation menu using HTML and CSS.
- Hero section with heading, description, and booking button.
- Laundry-related image displayed alongside the hero content.
- Responsive layout using CSS Flexbox and media queries.
- Viewport-based sizing to fit the screen.

## Technologies Used

- HTML5
- CSS3
  - Flexbox
  - Media Queries
  - CSS Transitions
  - CSS Pseudo-classes

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## Assignment Requirements

- Design a navigation bar with the specified sections.
- Create a two-column hero section.
- Include a service-related image.
- Use viewport units to fit the section within the screen.
- Deploy the project using Netlify.
